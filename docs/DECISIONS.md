# 결정 사항

2026-10-12 확정. 근거는 인수인계 문서(`earnings_tracker_handoff.md`) 6.4와 벤치마크(SCHD 배당 트래커) 분석.

| # | 항목 | 결정 | 이유 |
|---|---|---|---|
| 1 | 저장소 | 새 저장소 `earnings-tracker` | 벤치마크 테스트 저장소와 분리 |
| 2 | 데이터 저장 | 저장소 안 JSON (`data/`) | 혼자 쓰는 도구. 변경 이력이 git에 남고, 서버·DB 불필요 |
| 3 | 화면 기술 | 빌드 없는 HTML/CSS/JS 한 페이지 + 직접 그린 SVG 차트 | 벤치마크와 같은 구조. 의존성이 없어 유지보수 부담이 가장 적음 |
| 4 | 스크립트 | Python 표준 라이브러리만 | 설치 없이 어디서든 실행. 엑셀 생성 단계에서만 openpyxl 추가 예정 |
| 5 | 입력 방식 | Claude Code가 리서치 → JSON 수정 → 검증 → 커밋 | 지금까지의 방식("Claude에게 실적 반영 지시") 유지. 웹 입력 화면은 MVP에서 제외 |
| 6 | 구글 시트 역할 | MVP 완성 전까지는 시트가 마스터 → 10/28 빅테크 주간 전 웹으로 전환 → 이후 시트는 읽기 전용 보관 | Q3 시즌(10/13~)이 MVP보다 먼저 시작 |
| 7 | 자동화 범위 | 실적·컨센서스·비고는 수동. 자동화는 일정 경과 알림·주가반응·공시 교차검증만 후보 | 컨센서스는 무료 신뢰 출처가 없고 집계기관마다 다름 |
| 8 | 계산 필드 | 서프라이즈·영업이익률은 저장하지 않고 계산 | 시트 수식과 같은 규칙(입력 하나라도 비면 공란, 분모 0 방지). 컨센서스가 음수면 분모에 절대값 사용 |
| 9 | 정정 기록 | 시트 값을 바꾸면 `sheet_value`·`reason`·출처를 함께 남김 | "출처가 갈리면 고르지 않고 기록" 규칙 유지 |

## 아직 열려 있는 결정

- **공개 범위(배포 단계에서 결정):** GitHub Pages는 사이트가 공개되고, 비공개 저장소에서 쓰려면 Pro 요금제가 필요하다. 비고까지 비공개로 두려면 Cloudflare Pages + Access(무료 인증)가 대안.
- **시트에도 0단계 정정을 반영할지:** 전환 전까지 시트가 마스터이므로, 시트에도 같은 정정을 넣어야 두 쪽이 어긋나지 않는다. `DATA_ISSUES.md`의 '시트 반영 필요' 목록 참고.
