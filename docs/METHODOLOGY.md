# 작성 기준

시트 legend와 인수인계 문서 7장에서 옮긴 규칙. 화면 하단 '기준·출처'에 이 내용을 쓴다.

## 단위와 비교

- 매출·영업이익은 보고통화의 십억 단위. 원화는 1조원 = 1,000. 통화: 삼성전자·SK하이닉스 = KRW, ASML = EUR, 나머지 USD (TSMC는 ADR 환산 USD).
- 통화가 다르면 절대값을 비교하지 않고 % 지표(서프라이즈·YoY·영업이익률·주가반응)로만 비교한다.
- 영업이익은 실적치와 영업이익률만 관리한다. 영업이익 컨센서스 대비 결과는 비고에 문장으로 적는다.
- 은행(JPM·GS)은 영업이익 비적용. 순이익·EPS로 판단한다. GS 매출은 순매출(net revenues).
- 주가반응(2026-10-12부터): 발표 후 첫 거래일 종가 ÷ 직전 거래일 종가 − 1, `basis: close`. 장 후(amc) 발표는 다음 거래일, 장 전·장중 발표는 당일(휴장이면 다음 거래일)이 첫 거래일. GitHub Actions가 Yahoo Finance 종가로 매일 자동으로 채운다(`scripts/price_reaction.py`) — 사람이나 Claude가 넣지 않는다. 그 전에 입력한 값은 미국 = 시간외(`after_hours`), 한국 = 장중(`intraday`) 기준이며 그대로 둔다.

## 회계기간

역년 분기와 다른 회사는 YoY·QoQ 비교 시 기간을 적는다.

| 회사 | 규칙 | 예 |
|---|---|---|
| MU | 8/31에 가장 가까운 목요일 마감 | FQ3 2026 = 2026-02-27 ~ 05-28, FQ4 2026 = 05-29 ~ 09-03 (53주 연도) |
| NVDA | 1월 마지막 일요일 마감 | FQ2 2027 = 2026-04-27 ~ 07-26, FQ3 2027 = 07-27 ~ 10-25 |
| AAPL | 9월 마지막 토요일 마감 | FQ3 2026 = 2026-03-29 ~ 06-27, FQ4 2026 = 06-28 ~ 09-26 |
| MSFT | 6/30 마감 | FQ4 2026 = 2026-04 ~ 06, FQ1 2027 = 2026-07 ~ 09 |

## 업데이트 규칙

1. **발표 직후 순서:** 공식 자료(IR·실적발표·공시) → 신뢰할 만한 보도로 컨센서스 확인 → 수치 입력 → 상태를 발표완료로 → 비고 정리 → 검증 스크립트로 재확인.
2. **출처가 갈리면 고르지 않고 기록:** 고른 값은 `value`·`provider`·`asOf`, 다른 값은 `alts`.
3. **확인 못 한 값은 추정으로 채우지 않는다:** `value: null`과 `reason`.
4. **회계 왜곡 분리:** EPS가 지분평가이익 등 비영업 요인에 좌우되면 지표 `caution`에 적고, 영업이익·영업이익률로 판단한다.
5. **주가반응 해석 주의:** 같은 날 시장 전체가 급락했으면 실적 때문이라고 단정하지 않고 비고에 적는다.
6. **한국 기업 2단계:** 잠정치를 `stage: preliminary`로 입력하고, 확정치가 나오면 같은 이벤트를 갱신해 `final`로 바꾼다.
7. **통화가 다른 회사는 % 지표로만 비교한다.**
8. **회계연도 어긋남:** `period`에 날짜를 둔다.

## 출처

각사 실적발표·IR·공시(10-Q, 8-K, DART 등)와 공개 보도. 한국 컨센서스는 에프앤가이드 기본. 컨센서스는 집계기관·기준일에 따라 다르다. 투자 조언이 아니다.
